# Cafulon Restaurant DBMS

Database management system for Cafulon Restaurant & Dining, Colombo.

## Stack

- **Database:** MySQL 8
- **Backend:** Python + Flask
- **Frontend:** Bootstrap 5
- **Requirements:** [`webapp/requirements.txt`](webapp/requirements.txt)

## Setup

1. Run `restaurant_schema.sql` in MySQL to create DB + sample data
2. `pip install -r webapp/requirements.txt`
3. `python webapp/app.py`
4. Open `http://localhost:5000`
